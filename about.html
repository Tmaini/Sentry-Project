About Sentry

Sentry is a concept project built by Tushar as part of a web development and accessibility coursework assignment. It imagines what real-time link and download protection could look like for everyday web users.

The idea is simple: check a link or download the moment it appears, before a person has a chance to click on it.

How It Would Work

  1. A link or download appears on the screen.
  2. Sentry checks it against known warning signs.
  3. If anything looks risky, you see a plain-language warning before you can continue.

This is a class project, not a released product, but it is meant to reflect a realistic and accessible design.
