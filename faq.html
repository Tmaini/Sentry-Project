Frequently Asked Questions

Answers to common questions about the Sentry concept.

Is Sentry a real product yet?
Not yet - this is a concept built for a class project.
Would Sentry slow down my browsing?
No. Checks would happen instantly in the background.
What happens if a link looks risky?
You would see a plain warning before you could continue to the link or download.
Would Sentry collect my personal data?
The concept only checks links and downloads - it would not need to store personal browsing history.
